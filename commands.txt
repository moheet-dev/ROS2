get current ros2 topic list with message type:
ros2 topic list -t

turtlebot models:
export TURTLEBOT3_MODEL=waffle

TurtleBot with camera:
ros2 launch turtlebot3_gazebo turtlebot3_world.launch.py

Ros bridge:
ros2 launch rosbridge_server rosbridge_websocket_launch.xml

Ros web video server
ros2 run web_video_server web_video_server

Create ROS2 package:
ros2 pkg create --build-type ament_python turtlebot_services

Build a ROS2 package:
colcon build

Run a ROS2 service:
ros2 run robot_services move_service

Call a ROS2 service:
ros2 service call /move_service turtlebot_interfaces/srv/MoveRobot "{target_x: 3.0, target_y: 5.0}"
